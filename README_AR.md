# Chess Clock — خلفية شطرنج حية لأندرويد ♟️

تطبيق Android يحوّل تصميم ساعة الشطرنج إلى خلفية حية. قطع الشطرنج ثابتة، والعقارب تُرسم برمجيًا وتعرض الوقت الحقيقي وتتحدث كل ثانية.

## استخراج ملف APK بدون تثبيت Android Studio على الكمبيوتر

المشروع يحتوي على GitHub Actions workflow جاهز لبناء APK عبر الإنترنت:

1. نزّلي ملف `ChessClock_AndroidStudio_Project.zip` وفكّي ضغطه.
2. ارفعي محتويات المجلد إلى مستودع GitHub جديد (Repository) باسم `ChessClock`.
3. افتحي تبويب **Actions** في المستودع.
4. اختاري **Build Chess Clock APK** ثم **Run workflow**.
5. انتظري انتهاء البناء بنجاح، ثم افتحي نتيجة التشغيل (workflow run).
6. من قسم **Artifacts** نزّلي `Chess-Clock-debug-apk.zip` وفكّي ضغطه. ستجدين `app-debug.apk`.
7. انقلي ملف APK إلى موبايل سامسونج وافتحيه، واسمحي بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.
8. افتحي تطبيق **Chess Clock** واضغطي **تعيين خلفية الساعة**. اختاري الشاشة الرئيسية، أو الرئيسية وشاشة القفل إذا أتاح إصدار One UI ذلك.

## البناء محليًا باستخدام Android Studio

- افتحي مجلد المشروع في Android Studio.
- استخدمي JDK 17 و Android SDK Platform 35.
- شغّلي مهمة `:app:assembleDebug`.
- ملف APK الناتج سيكون في `app/build/outputs/apk/debug/app-debug.apk`.

## معلومات
- الحد الأدنى: Android 6.0 (API 23).
- لا يحتاج التطبيق إلى صلاحيات إنترنت أو موقع.
- الخلفية الحية تُحدّث العقارب كل ثانية عندما تكون ظاهرة، وتتوقف عن التحديث عندما لا تكون ظاهرة لتقليل استهلاك البطارية.
- دعم خلفية الشاشة الرئيسية والقفل معًا يعتمد على إصدار سامسونج One UI.
